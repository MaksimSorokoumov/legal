Это Уведомление описывает, как обрабатываются данные при использовании мобильного приложения **«Умножение»** (пакет: `com.kamchatka.trenajor_tablici_umnojeniya.huawei`) в Huawei AppGallery.

В приложении нет аккаунтов, регистрации и входа. Мы не собираем ваше имя, телефон, адрес электронной почты и контакты. Приложение предназначено для обучения таблице умножения и работает полностью офлайн.

## 1. Какие данные обрабатываются

### 1.1 Данные, обрабатываемые локально на устройстве
Приложение сохраняет на устройстве пользователя (через SharedPreferences):
- прогресс обучения, пройденные таблицы и результаты занятий;
- локальную статистику занятий: количество ответов, время ответов, серию дней занятий;
- разблокировки режимов («Супермарафон», «Быстрый счёт», «Кроссворд»);
- баланс подсказок в режиме «Кроссворд»;
- настройки приложения: тему оформления, звук и лимит времени;
- технические служебные значения, например время последней полноэкранной рекламы.

Эти данные используются исключительно для работы приложения и не передаются третьим лицам. Статистика занятий хранится только на устройстве.

### 1.2 Данные, которые могут обрабатываться сторонней рекламной сетью
В приложении используется SDK **Yandex Mobile Ads** для показа рекламы (баннеры, полноэкранная реклама после занятия и реклама с вознаграждением за разблокировку режимов и подсказок).
При показе рекламы сторонний SDK может обрабатывать:
- рекламные идентификаторы устройства (например, OAID/AAID/GAID, если доступны);
- IP-адрес и сетевые параметры;
- технические данные устройства и приложения;
- события рекламы (показы, клики, технические события доставки рекламы).

Цели: показ рекламы, ограничение частоты, антифрод и аналитика эффективности рекламы.

### 1.3 Данные, которые могут обрабатываться сторонним SDK аналитики
В приложении используется SDK **Yandex AppMetrica** для статистики использования приложения.
SDK может обрабатывать:
- технические данные устройства и приложения (модель устройства, версия ОС, версия и сборка приложения, язык, параметры экрана);
- идентификаторы устройства, используемые для статистики и атрибуции установок;
- IP-адрес и сетевые параметры;
- обезличенные события использования приложения и статистику сессий (открытые экраны, использованные функции, запуски приложения);
- технические отчёты об ошибках и сбоях.

Цели: статистика использования приложения, аналитика аудитории и удержания, выявление технических ошибок и сбоев, статистика установок.

### 1.4 Передача содержимого по инициативе пользователя
Кнопка «Поделиться» передаёт только ту ссылку или текст, которые пользователь сам отправляет выбранным приложением. Приложение не передаёт этот контент оператору.

## 2. Разрешения приложения

Приложение объявляет доступ к сети (`INTERNET`) для загрузки рекламы и отправки технических данных сторонними SDK. Приложение не запрашивает доступ к микрофону, файлам, фотографиям, контактам, точному местоположению и камере.

В карточке магазина указан полный список разрешений, включая технические разрешения, объявляемые сторонними SDK, встроенными в приложение. Такие разрешения используются соответствующими SDK только для целей, описанных в разделах 1.2 и 1.3.

## 3. Правовые основания обработки

Обработка персональных данных выполняется:
- для обеспечения функциональности приложения и предоставления услуг пользователю;
- на основе наших законных интересов в монетизации приложения через показ рекламы и в измерении использования приложения;
- на основании согласия пользователя, если это требуется применимым законодательством.

Используя приложение, вы выражаете согласие на обработку данных в соответствии с данным Уведомлением.
