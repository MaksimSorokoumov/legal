Это Уведомление описывает, как обрабатываются данные при использовании мобильного приложения **«Сапёр»** (пакет: `com.kamchatka.minesweeper.huawei`) в Huawei AppGallery.

В приложении нет аккаунтов, регистрации и входа. Мы не собираем ваше имя, телефон, адрес электронной почты и контакты. Игровые режимы работают полностью офлайн; сеть нужна только для рекламы, аналитики и ежемесячного рейтинга игроков.

## 1. Какие данные обрабатываются

### 1.1 Данные, обрабатываемые локально на устройстве
Приложение сохраняет на устройстве пользователя (через SharedPreferences):
- статистику классического режима: лучшие времена, победы и поражения по сложностям;
- незаконченную партию классического режима для восстановления после выхода;
- прогресс режима «Выживание»: операция, пройденные уровни и рубежи, жизни, очки и медали;
- профиль режима «Побег»: монеты, улучшения, бустеры и звёзды уровней;
- настройки: фон доски, звук, музыка, размер кастомного поля, язык интерфейса;
- имя игрока (никнейм, который вы задаёте сами) и случайный внутренний идентификатор игрока;
- технические служебные значения, например время последней полноэкранной рекламы.

Эти данные используются исключительно для работы приложения. Никнейм и идентификатор дополнительно используются для рейтинга (раздел 1.4). Остальные локальные данные не передаются третьим лицам.

### 1.2 Данные, которые могут обрабатываться сторонней рекламной сетью
В приложении используется SDK **Yandex Mobile Ads** для показа рекламы (баннеры, полноэкранная реклама и реклама с вознаграждением, которую пользователь запускает сам — например, чтобы вызвать медика в «Выживании»).
При показе рекламы сторонний SDK может обрабатывать:
- рекламные идентификаторы устройства (например, OAID/AAID/GAID, если доступны);
- IP-адрес и сетевые параметры;
- технические данные устройства и приложения;
- события рекламы (показы, клики, технические события доставки рекламы).

Цели: показ рекламы, ограничение частоты, антифрод и аналитика эффективности рекламы.

### 1.3 Данные, которые могут обрабатываться сторонним SDK аналитики
В приложении используется SDK **Yandex AppMetrica** для статистики использования приложения.
SDK может обрабатывать:
- технические данные устройства и приложения (модель устройства, версия ОС, версия и сборка приложения, язык, параметры экрана);
- идентификаторы устройства, используемые для статистики и атрибуции установок;
- IP-адрес и сетевые параметры;
- обезличенные события использования приложения и статистику сессий (открытые режимы, исходы партий, показы роликов);
- технические отчёты об ошибках и сбоях.

Имя игрока и внутренний идентификатор игрока в аналитику не передаются.

Цели: статистика использования приложения, аналитика аудитории и удержания, выявление технических ошибок и сбоев, статистика установок.

### 1.4 Данные, передаваемые на сервер рейтинга
Для ежемесячного рейтинга игроков приложение отправляет на сервер оператора:
- случайный внутренний идентификатор игрока (не связан с вашим именем, аккаунтом или устройством);
- имя игрока (никнейм, видимый всем в таблице; не используйте настоящее полное имя);
- результат партии: режим и время, а для «Выживания» также очки, пройденные уровни и число подрывов.

Сервер технически получает IP-адрес устройства — исключительно для защиты от накруток. Записи старше двух месяцев удаляются автоматически. Отправка выполняется в фоне при наличии сети и не влияет на игровой процесс.

### 1.5 Передача содержимого по инициативе пользователя
Кнопка «Поделиться» передаёт только тот текст, который пользователь сам отправляет выбранным приложением. Приложение не передаёт этот контент оператору.

### 1.6 Покупки
В версии для Huawei AppGallery покупки не предусмотрены: платных функций и подписок в этой версии нет. SDK покупок другого магазина в этой версии не используется.

## 2. Разрешения приложения

Приложение объявляет доступ к сети (`INTERNET`) и состоянию сети (`ACCESS_NETWORK_STATE`) для загрузки рекламы, отправки результатов рейтинга и технических данных сторонними SDK. Приложение не запрашивает доступ к микрофону, файлам, фотографиям, контактам, точному местоположению и камере.

В карточке магазина указан полный список разрешений, включая технические разрешения, объявляемые сторонними SDK, встроенными в приложение. Такие разрешения используются соответствующими SDK только для целей, описанных в разделах 1.2 и 1.3.
