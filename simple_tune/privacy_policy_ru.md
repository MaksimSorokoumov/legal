Это Уведомление описывает, как обрабатываются данные при использовании мобильного приложения **Simple Tune** (пакет: `com.kamchatka.simpletune.huawei`) в Huawei AppGallery.

В приложении нет аккаунтов, регистрации и входа. Мы не собираем ваше имя, телефон, адрес электронной почты и контакты.

## 1. Какие данные обрабатываются

### 1.1 Данные, обрабатываемые локально на устройстве
Приложение сохраняет на устройстве пользователя:
- выбранный инструмент, строй, режим и струну (через SharedPreferences);
- настройки высоты тона: эталон A4 и темперацию (через SharedPreferences);
- настройки приложения: тему оформления, язык интерфейса, подсказки строя, свечение и звук попадания в ноту;
- технические служебные значения, например время последней полноэкранной рекламы.

Эти данные используются исключительно для работы приложения и не передаются третьим лицам.

### 1.2 Данные, которые могут обрабатываться сторонней рекламной сетью
В приложении используется SDK **Yandex Mobile Ads** для показа рекламы через платформу Huawei AppGallery.
При показе рекламы сторонний SDK может обрабатывать:
- рекламные идентификаторы устройства (например, OAID/AAID/GAID, если доступны);
- IP-адрес и сетевые параметры;
- технические данные устройства и приложения;
- события рекламы (показы, клики, технические события доставки рекламы).

Цели: показ рекламы, ограничение частоты, антифрод и аналитика эффективности рекламы.

### 1.3 Данные, которые могут обрабатываться сторонним SDK аналитики
В приложении используется SDK **Yandex AppMetrica** для статистики использования приложения.
SDK может обрабатывать:
- технические данные устройства и приложения (модель устройства, версия ОС, версия и сборка приложения, язык, параметры экрана);
- идентификаторы устройства, используемые для статистики и атрибуции установок;
- IP-адрес и сетевые параметры;
- события использования приложения и статистику сессий (открытые экраны, использованные функции, запуски приложения);
- технические отчёты об ошибках и сбоях.

Цели: статистика использования приложения, аналитика аудитории и удержания, выявление технических ошибок и сбоев, статистика установок.
SDK не получает содержимое вашего аудиовхода: поток с микрофона обрабатывается на устройстве для определения высоты тона и не сохраняется и не передаётся.

## 2. Разрешения приложения

Само приложение использует следующие разрешения:
- `INTERNET` и `ACCESS_NETWORK_STATE` — загрузка рекламы и сетевые запросы;
- `RECORD_AUDIO` — запись звука для определения высоты тона (тюнер);
- `MODIFY_AUDIO_SETTINGS` — изменение настроек аудио для воспроизведения синтезатора.

В карточке магазина указан полный список разрешений, включая технические разрешения, объявляемые сторонними SDK, встроенными в приложение. Такие разрешения используются соответствующими SDK только для целей, описанных в разделах 1.2 и 1.3 (показ рекламы, ограничение частоты, антифрод, аналитика).

Приложение не получает доступ к файлам, фотографиям, контактам, точному местоположению и камере, не хранит аудиозаписи.
